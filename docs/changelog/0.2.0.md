# terraria-seed-searcher v0.2.0

Date: 2026-10-17

本版本支持小世界, 中世界和大世界, 出生点范围不再需要手动填写; CUDA 在网页端的搜索速度也不再被每块一次的进程启动拖住.

## Highlights

- 支持小世界 (4200 x 1200), 中世界 (6400 x 1800) 和大世界 (8400 x 2400), CPU, CUDA, MLX 与 WebGPU 四个后端都可用.
- 出生点范围由世界规则自动推导, 高级参数里不再需要填写; 换世界尺寸时模拟列数会给出对应默认值.
- CUDA 搜索器改为一个任务一个常驻进程, 工作块从 40 万提高到 100 万.
- 每批进度行末尾输出 GPU 耗时, 可以直接区分 GPU 计算与边界开销.

## Features

- 搜索: 新增世界尺寸参数. 工作台在高级参数里选择, 命令行用 `--world small|medium|large`.
- 搜索: 出生点窗口按世界中心加减 5 再留 64 列标注容差推导, 标注略有偏差也能兜住.
- CUDA: 批大小按可用显存自动收缩, 显存不够时不再分配失败, 启动日志会打印实际值.
- 进度: 每批末尾给出 `GPU x.xxx s`.

## Bug Fixes

- CUDA: 修复网页端速度远低于同一台机器命令行的问题. 原因是每 40 万种子重起一次进程, 快卡上这项固定开销盖过了 GPU 时间.
- 地形: 修复地表下限不是整数时的钳制边界. 小世界的 `1200 * 0.17` 是 204.00000000000003, 大世界的 `2400 * 0.17` 是 408.00000000000006, 按严格小于比较会漏掉一次钳制, 后续随机数消耗随之分叉.
- WebGPU / MLX: 分段窗口改用闭区间, 与 CUDA 和参考实现一致; 原写法在大世界的窗口端点会差一列.
- WebGPU: 设备自检扩展到三个世界的全宽剖面.

## Upgrade Notes

1. 浏览器 WebGPU 的旧任务需要新建: 内核与参考实现已变化, 旧任务会提示搜索器版本已变化.
2. 大世界用户需要在高级参数里选择世界尺寸, 模拟列数默认会用 4400; 小世界默认 2300.
3. 原生任务 (CPU / CUDA / MLX) 不需要迁移, 旧任务按中世界继续.
4. 换世界后先用已知种子复核一次: 真种子在同一份观测上应当拿到 1.0000, 否则多半是世界尺寸或标注选错了.
