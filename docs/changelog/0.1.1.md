# terraria-seed-searcher v0.1.1

Date: 2026-10-17

本版本是首个实际发布的预编译版本. 工作台改为 Go 单文件程序, CUDA 搜索器以独立二进制随包提供.

## Highlights

- 下载归档解压后直接运行, 不需要安装 Python, CUDA Toolkit 或 MSVC.
- Windows 与 Linux 的 CUDA 搜索器静态链接 cudart, 只依赖 NVIDIA 驱动.
- CUDA 构建覆盖 Maxwell 到 Blackwell 的显卡架构, 单卡和多卡都能直接用.
- 修复 Windows 上 CUDA 编译器崩溃和 CRT 链接问题, Windows 构建已通过 CI.

## Breaking Changes

- 工作台服务端由 Python 改为 Go, 不再需要 Python 3.11 或任何第三方包.
- CUDA 搜索器文件名由 `sweep2` 改为 `sweep`, 旧命令行需要更新.
- 旧 Python 版保存的搜索任务不保证能在新版本中继续.

## Upgrade Notes

1. 下载对应平台的归档并解压到同一目录.
2. 确认 `terraria-seed-searcher` 与 `sweep` / `sweep-cpu` 位于同一目录.
3. 运行 `terraria-seed-searcher --open`, 或直接双击可执行文件.
4. 需要多卡时, 在粗筛设置的 GPU 编号中填 `-1`.

## Features

- 工作台: 页面资源嵌入可执行文件, 支持截图导入, 网格标定, 拼接, 标注, 搜索和候选查看.
- 搜索: CUDA 搜索器支持 `--device all`, 自动按显卡数平分种子区间.
- 搜索: 工作台 GPU 编号支持 `-1`, 等价于全部显卡.
- 标注: 标注页新增图片不透明度滑块, 方块工具名称改为地表方块.
- 标注: 台阶化 (斜坡等) 格子统一按地表方块处理, 旧斜坡标记自动转换.
- 版本: `--version` 和页面页脚显示当前构建版本.

## Bug Fixes

- Windows: 拆分 CUDA 设备代码与主机入口, 让 nvcc 只处理设备代码, 主机线程逻辑交给普通 C++ 编译器.
- Windows: 主机对象改用 `/MT`, 与 nvcc 的静态 CRT 一致, 修复 `LNK2038` 和 `__imp_atof` 未解析.
- Windows: 改用 VS 2022 runner, 避开 CUDA 12.8 与 VS 2026 的兼容问题.

## Performance

- CI 缓存 CUDA Toolkit 目录, 命中时跳过完整安装.
- `nvcc -t 0` 并行编译多个显卡架构.
