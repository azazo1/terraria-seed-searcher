# terraria-seed-searcher v0.1.0

Date: 2026-10-17

本版本是首个提供预编译产物的版本. 工作台改为 Go 单文件程序, 搜索器以独立二进制随发布包提供.

## Highlights

- 从 GitHub Releases 下载后直接解压运行, 不需要安装 Python, CUDA Toolkit 或 MSVC.
- Windows 与 Linux 的 CUDA 搜索器静态链接 cudart, 只依赖 NVIDIA 驱动.
- CUDA 构建覆盖 Maxwell 到 Blackwell 的显卡架构.
- 单卡与多卡都能直接使用, 工作台 GPU 编号填 -1 时自动平分到全部显卡.

## Breaking Changes

- 工作台服务端由 Python 改为 Go, 不再需要 Python 3.11 及第三方包.
- CUDA 搜索器文件名由 `sweep2` 改为 `sweep`, 旧命令行需要更新.
- 旧 Python 版保存的搜索任务不保证能在新版本中继续.

## Upgrade Notes

1. 下载对应平台的归档并解压到同一目录.
2. 确认 `terraria-seed-searcher` 与 `sweep` / `sweep-cpu` 位于同一目录.
3. 运行 `terraria-seed-searcher --open`, 或直接双击可执行文件.
4. 需要多卡时, 在粗筛设置的 GPU 编号中填 `-1`.
