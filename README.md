# terraria-seed-searcher

从游戏截图反推泰拉瑞亚世界种子的工具集与完整方法论.

> 泰拉版本: 1.4.5.8

## 结果

```
种子      (种子已隐去)
参数      中世界 / 猩红 / 专家
验证      用户游戏内核对通过
```

搜索空间为 `[0, 2^31)`, 即 21.5 亿个种子; 在两张 RTX 4090 上约 40 分钟扫完.

## 问题建模

泰拉瑞亚的地图 ID 是一个 32 位有符号整数, 但负数会被取绝对值, 所以只需扫 `[0, 2^31)`.
世界生成由 `WorldGenerator` 的若干 pass 逐段推进, 每个 pass 进入时都会用
`UnifiedRandom` (.NET 的减法随机数发生器, 56 个 int 的内部状态) 重新播种.
因此给定种子, 出生点附近的地表高度是**完全确定**的, 这就是可以用来比对的特征.

## 方法概要

1. **取观测**. 用游戏主画面截图 (不是地图), 提取出生点附近逐格的地表高度.
2. **定标**. 求出每格的像素宽, 相位, 以及出生点在剖面里的列号. 这一步最容易出错, 见下文.
3. **判据**. 模拟剖面对齐后计算"逐格命中率" (残差不超过半格的列占比), 纵向偏移用残差中位数消掉.
4. **搜索**. GPU 双内核: 一个内核逐种子模拟并写出所需列的窗口, 另一个内核对窗口打分.
5. **验证**. 用已知种子造一份同格式观测, 跑同样的搜索, 确认真种子拿满分且假候选带足够低.

## 快速上手

搜索需要 CUDA 环境. 以本项目的路径为例:

```shell
nvcc -O3 -arch=sm_89 -o sweep2 src/cuda/sweep2.cu -lm

# 全空间分两半并行 (两块卡各一半)
./sweep2 data/observed_manual.txt --range 0 1073741824 \
    --tol 0.5 --offer 0.55 --batch 400000 --device 0 \
    --marker 141 --spawn-lo 3180 --spawn-hi 3220 --cols 3400
```

参数含义:

| 参数 | 含义 |
| --- | --- |
| `--marker` | 出生点在观测剖面里的列号 |
| `--spawn-lo` / `--spawn-hi` | 出生点的世界列范围 (**不是**减去 marker 后的值) |
| `--cols` | 需要模拟到第几列 |
| `--tol` | 命中判据的容差, 单位格 |
| `--offer` | 只保留分数高于此值的种子 |
| `--scales` | 逗号分隔的比例尺集合 |
